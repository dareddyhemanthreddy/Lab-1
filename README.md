# Lab 1 — Sorting Algorithms

This repository contains the C++ implementation for Lab 1, focused on sorting an input collection and examining the resulting order.

## Contents

- [`Lab1/sorting.cpp.cpp`](Lab1/sorting.cpp.cpp) — sorting program
- `Lab1/output/` — output or supporting files, if provided

## Build and run

Requires a C++ compiler such as `g++`.

```bash
g++ -std=c++17 -Wall -Wextra "Lab1/sorting.cpp.cpp" -o sorting
./sorting
```

Follow the prompts printed by the program to provide input. The repository also contains a prebuilt Windows executable; compiling from source is recommended for your platform.

## Learning goals

- Practice implementing and testing sorting logic.
- Observe how the program transforms input into sorted output.
- Compile and run a standalone C++ program.
